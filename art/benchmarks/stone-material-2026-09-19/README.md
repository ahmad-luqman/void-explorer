# Physical-scale stone material review

19 September 2026. Apple M4 Max / Metal, 128 GiB RAM, macOS 26.6.2; Chromium 153.0.8010.12, 1440×960, DPR 1. Tests run serially under a task-local sleep inhibitor, without concurrent unit/build/GPU-test workloads. Normal user applications are not controlled. These are finite desktop samples, not physical-phone or low-powered-device certification.

The baseline is private v37/root `165dfd8`, with images in `../../milestones/composed-*`. `first-material-bay-webgpu.png` is the first development view. Final production images use the `stone-*` prefix in the milestones directory. Walking captures stop at roughly 28–32 m, so they are comparable viewpoints rather than pixel-identical renderings.

The new material reuses the 512² prepared grit texture and existing optional slate image. It adds six filtered texture lookups per stone fragment and 24 bytes of instance attributes per stone (16,800 bytes maximum across the full 700-prop budget). Existing geometry, draw counts, collision, colors and placement are retained. Triplanar coordinates include actual nonuniform instance scale; identity-based phase is independent of collection order, origin and world rotation. Bedding and relief fade with pixel footprint. Dust lightens upward faces without replacing the underlying faceted silhouettes.

No new texture was generated. The source ground image and exact prompt remain in their existing repository locations. GLSL is authoritative and the TSL shade function is regenerated by the existing shader port script. Image-failure coverage exercises the existing procedural fallback on both renderers.

Full unit validation: 144 tests / 37 files pass in 30.55 seconds with `--maxWorkers=1 --testTimeout=60000`; TypeScript, scoped lint and static export pass. A later assertion refinement compares the stone coordinate scale directly with actual instance-matrix column lengths, rather than merely restating the coordinate formula. Its focused validation is recorded below.


WebGL settled samples retain 16.7 ms medians and 16.8 ms maxima for orbit High, coast High and coast Low, with no frame above 50 ms. These six-second settled samples match the preceding composition pass within the refresh interval; they do not quantify GPU headroom or establish performance on other hardware. First-use material graph/upload costs and previously recorded moving/cold-entry outliers remain outside this narrow comparison.

Final production suites pass all seven checks on each renderer: WebGL 5.3 minutes, WebGPU 5.5 minutes. Coverage includes Ember Relay and Glass Choir walking/survey/journal/restoration/navigation loops, normal and missing-image coastal ground, High/Low frame sampling, orbital descent/landing/return and saved coastal journeys including legacy terrain profiles. The extended normal-image case reaches the cliff guard and walks back. Final focused formation/coordinate tests pass all three cases in 855 ms; TypeScript and scoped lint pass after the assertion refinement. Runtime source and validated static output are unchanged.

Firefox and WebKit final loaded-image/High/Low/extended-walk cases pass in 30.9 and 29.8 seconds. Bay, Low and overlook captures are retained for both engines. These remain desktop engine checks; installed Safari and physical phones are not certified. The material improves close rock/ground continuity without closing the wider shoreline and landscape-art requirements.
